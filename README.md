# Puzzle-Game
## Description
A C#/.NET puzzle game where the player must click on the correct box to have all other boxes match each other. The project tfocuses on user input handling, game logic, and control flow.

## Technologies Used
- C#
- .NET
- Visual Studio
  
## Features
- Interactive console-based gameplay
- Input validation to prevent invalid moves
  
## What I Learned
- Designing game logic using C# functions
- Validating user input
- Debugging logical errors
